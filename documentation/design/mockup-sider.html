Sider에서 가져온 패턴

  • 오른쪽 세로 아이콘 레일 + 홈 화면(인사말, 도구 카드 그리드)
  • ‘현재 탭’ 컨텍스트 카드: 지금 열린 LMS 페이지를 감지해 맞는 작업을 바로 제안
  • 그라디언트 테두리 입력창 + @과목, 현재 탭 같은 컨텍스트 칩
  • 질문 → 결과 카드 → 후속 제안 칩 흐름(②), 단계 카드 + 진행 바(④)

uniDock에 맞춘 부분 / 확인할 점

  • Sider 보라에 브랜드 크림슨을 섞은 그라디언트 — AI 기능 카드에만 사용
  • 입력창은 LLM이 아니라 키워드 검색/필터로 동작하게 설계 가능 (“이번 주”, “운영체제” 파싱)
  • 현재 탭 감지는 기존 content script로 가능하지만 ‘홈’ 화면은 새로 만드는 화면
  • 상단 탭 → 오른쪽 레일, 그림자·그라디언트 사용 — 기존 DESIGN.md와 다름
