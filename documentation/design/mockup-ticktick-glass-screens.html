현재 기능과의 대응

  • ① 내 과목 → ②③④ 과제 / 녹화 강의 / 강의 자료 세그먼트 (기존 CoursesScreen)
  • ⑤⑥ 할 일·일정 세그먼트, 일정의 시작·종료일과 종류 필터(전체·과제·공지·기타)
  • ⑦ 기존 ItemDetail 필드 그대로, 유일한 주 버튼은 LMS에서 열기
  • ⑧⑨ 자동 재생 상태·다음 영상·영상 선택, ⑩⑪ 자막 감지와 AI 자막 동의 카드, ⑫ 정보·설정 화면

기존 DESIGN.md에서 바뀌는 점

  • 상단 4칸 탭 → 하단 떠 있는 유리 탭 바, ‘정보’가 탭 바의 ‘설정’으로
  • 구분선 행 → 행마다 유리 카드, 설정·메타는 유리 카드 안의 구분선 행
  • 새로고침은 제목 옆 아이콘, 화면별 주 동작은 하단 유리 바로 이동
  • 과목 색 태그 추가 · 읽기 전용 상태는 원형 아이콘, 네모 체크박스는 실제 선택에만

확인할 점

  • 상태 아이콘: 시계=미제출, 채운 체크=제출됨, 느낌표=마감 지남, 자물쇠=잠김 — 행 전체가 상세로 가는 버튼이고 아이콘은 따로 누르지 않음
  • 배포 빌드에서 자동 재생 탭은 ‘검토 중’ 비활성 상태로 표시
  • 과목 색은 LMS 데이터가 아니라 이름 기반으로 로컬 배정
  • 행마다 backdrop-filter는 100행 목록에서 무거움 — 실제로는 카드 배경만 반투명, blur는 탭 바·하단 바에만 권장
