# 모서리 R값 (TickTick 글래스 리디자인)

리디자인 시안(`mockup-ticktick-glass-screens.html`)의 모서리 반경을 v0.5.1 UI 개편에 적용한다. 구현 기준은 `DESIGN.md` 4절이며, 아래 표는 시안의 반경 선택과 동심 규칙을 설명한다.

## 기준

- 값은 Material 3 셰이프 단계에서 가져온다.
- 겹치는 요소는 Apple의 동심 규칙을 따른다: **안쪽 R = 바깥 R − 둘 사이 여백**.
- 아래 다섯 값 외의 R값은 쓰지 않는다. 새 컴포넌트도 크기가 가장 가까운 단계를 고른다.

## 토큰

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `--r-xs` | 4px | 체크박스, 과목 태그, 진행 바 |
| `--r-sm` | 8px | 파일 확장자 아이콘, 행 안의 작은 버튼(강의 열기, 로그아웃 등) |
| `--r-md` | 12px | 버튼, 과목 이니셜 사각형, 앱 아이콘, 안내 줄, 날짜·과목 선택 필드 |
| `--r-lg` | 16px | 유리 카드, 목록 행 카드, 하단 동작 바 |
| `--r-full` | 999px | 하단 탭 바와 선택 표시, 세그먼트, 칩, 상태 칩, 토글과 손잡이 |

## 동심 규칙 적용

| 바깥 | 여백 | 안쪽 |
| --- | --- | --- |
| 하단 동작 바 `--r-lg` 16 | 4px | 버튼 `--r-md` 12 |
| 하단 탭 바 `--r-full` | 4px | 선택 표시 `--r-full` |
| 세그먼트 `--r-full` | 3px | 선택된 항목 `--r-full` |

캡슐 안에는 캡슐을 넣는다. 사각 카드 안에 요소를 넣을 때 여백이 달라지면 안쪽 단계를 다시 계산한다(16 − 여백에 가장 가까운 단계).

## 하지 않는 것

- 9·10·11px처럼 단계 사이 값을 새로 만들지 않는다.
- 작은 요소에 큰 단계를 주지 않는다: 18px 체크박스에 `--r-lg`를 주면 원으로 보여 상태 아이콘(원형)과 구분되지 않는다. 네모 = 선택 가능, 원 = 상태 표시 구분이 R값에 달려 있다.
