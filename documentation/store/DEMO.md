# 촬영용 데모

프로젝트 루트에서 실행합니다.

```bash
npm run demo
```

처음 실행할 때 브라우저가 없다는 오류가 나오면 `npx playwright install chromium`을 실행하세요.

Playwright가 제공하는 Chromium(Chrome for Testing)을 별도 임시 프로필로 열고, 현재 production 확장과 실제 오른쪽 사이드패널을 자동으로 로드합니다. 기존 Chrome의 로그인·쿠키·방문 기록은 사용하지 않습니다. 터미널은 촬영하는 동안 열어 두세요.

주소창은 `mylms.korea.ac.kr`이지만 페이지와 API 응답은 스크립트가 로컬에서 제공하는 가상 데이터입니다. 등록되지 않은 웹 요청은 차단하거나 404로 응답합니다. 실제 계정 로그인은 필요하지 않습니다.

- 과목 3개, 과제와 제출 상태, 마감일, 전체 일정, Todo, 녹화 강의 목록을 조작할 수 있습니다.
- 녹화 강의 재생·실제 LTI·자막은 제공하지 않습니다. 목록의 링크를 열어도 실제 LMS에 연결하지 않습니다.
- 가상 수업명과 과제는 `scripts/demo-data.mjs`에서 변경하고 다시 실행하세요. 날짜는 실행 시점을 기준으로 생성합니다.
- 패널을 닫았다면 확장 프로그램 메뉴에서 uniDock을 클릭하세요.
- macOS에서는 Shift+Command+4로 원하는 영역을 캡처할 수 있습니다. 공개 이미지에는 ‘가상 데이터를 사용한 데모 화면’ 표시를 유지하세요.
- 브라우저 창을 닫거나 터미널에서 Ctrl+C를 누르면 종료하고 임시 프로필을 삭제합니다.

자동 검증 및 화면 캡처:

```bash
npm run demo -- --smoke
```

결과는 `output/demo/`에 저장됩니다. 이는 가상 데이터 기반 검증이며 실제 LMS/SSO/강의 재생 검증이 아닙니다. 배포용 확장에는 데모 데이터가 포함되지 않습니다.
