## 등록 정보

- 이름: uniDock
- 기본 언어: 한국어
- 카테고리 후보: 교육(대시보드의 현재 분류 확인)
- 짧은 설명: 고려대 LMS 과제·일정·녹화·수업 자료 조회, 자막 저장과 AI 자막 생성, 선택 영상 순차 재생, PDF·PPTX·PPT 다운로드를 지원하는 비공식 학습 도우미.

- 0.3.0 범위(이전): 설정 화면에서 켜는 LMS 공지 팝업·미참여 설문 안내 자동 닫기(기본 꺼짐, 켤 때만 lms.korea.ac.kr 선택 권한 요청), 녹화 강의 목록의 LearningX 게시판 KU 플레이어 영상, 일정의 과제·공지·기타 구분을 추가했습니다. 할 일 마감 늦은 순 정렬과 녹화 강의 바로 열기(0.2.1), 다크 모드와 접근성 개선(0.2.0), 선택적 사용 통계, PDF·PPTX·PPT 자료, 업데이트 안내는 그대로 유지됩니다.

## 상세 설명 (복사 가능)

uniDock은 기존 고려대학교 LMS 로그인 세션으로 과목·과제·마감일·일정·녹화 강의를 확인하는 비공식 Chrome Side Panel 학습 도우미입니다.

• 과목별 과제와 제출 상태, 마감일 확인
• 할 일·일정 목록(과제·공지 구분), 항목별 상세와 보기 설정
• 선택 시 LMS 공지 팝업과 미참여 설문 안내 자동 닫기(기본 꺼짐; 설문 참여·제출이나 ‘오늘 하루 보지 않기’ 선택은 하지 않음)
• 모듈별 녹화 강의 후보와 게시판 글에 포함된 KU 플레이어 영상 탐색, 사용자가 선택한 LMS/LTI 탭 또는 플레이어 열기
• 주차학습 모듈·게시판·공지에 첨부된 강의 자료(PDF·PPTX·PPT) 조회와 전체/선택 다운로드
• 한국어 질문 템플릿 복사와 ChatGPT 시작 페이지 열기; 자료 첨부·제출은 사용자가 직접 수행
• 화면 자막 우선 감지, XML/VTT 한국어 우선 선택 및 시간 포함 TXT·JSON 다운로드
• 자막이 없는 강의의 AI 자막 생성: Google 계정으로 로그인한 뒤 확인을 누르면 현재 강의의 음성만 자막 서버로 보내고, 결과를 자막 화면에 ‘AI 생성’으로 표시·TXT·JSON 저장(계정당 주 7회)
• 선택한 녹화 강의 순차 재생(기본 꺼짐): 체크한 영상만 체크한 순서대로, 보이는 전용 탭에서 정상(1x) 속도로 재생. 배속·숨김 탭 재생·출석 처리 없음

아이디나 비밀번호를 입력받거나 저장하지 않습니다. LMS 정보·자막·자료·질문을 분석 서비스나 외부 AI에 자동 전송하지 않습니다. AI 자막 생성을 직접 시작한 경우에만 현재 강의의 음성을 개발자가 운영하는 자막 서버로 보냅니다. 이때 LMS 쿠키·토큰, 강의 URL, 과목 ID, 강의 제목은 보내지 않습니다. 음성은 처리 후 삭제하고 자막은 최대 6개월 보관합니다. 사용 통계는 기본 비활성이며, 설정 화면에서 동의한 경우에만 화면·버튼 사용, 기능 성공·실패, 패널 표시·활성 시간, 버전과 무작위 설치 식별자를 PostHog EU로 보냅니다. LMS 계정·내용·URL·입력값이나 화면 녹화는 수집하지 않습니다. 거절해도 모든 학습 기능을 사용할 수 있으며 언제든 철회할 수 있습니다. 광고 추적·데이터 판매는 없습니다. 확장은 파일 내용을 읽거나 업로드하지 않으며 외부 서비스 첨부·제출은 사용자가 직접 결정합니다. 자동 재생·과제 제출·업로드·글쓰기·수정·삭제·출석 위조·keepalive는 지원하지 않습니다.

LMS에서 평소처럼 로그인하고 탭을 선택한 뒤 uniDock에서 조회하세요. 외부 플레이어 자막은 해당 탭에서 도구 모음 uniDock 아이콘을 눌러 임시 접근을 허용한 후 감지합니다. 화면 목록이 없으면 KU 플레이어의 XML/VTT 자막을 조회합니다. 외부 CDN의 CORS/CSP 제한 또는 플레이어 설정 구조 차이로 감지가 제한될 수 있습니다.

고려대학교와 공식 제휴 관계가 없습니다. Chrome 114 이상이 필요하며 서비스 변경에 따라 조회가 제한될 수 있습니다. 통계 공유 설정, 동의 후 생성한 설치 식별자, 팝업 자동 닫기 켜짐/꺼짐 설정, 순차 재생 목록의 최소 식별자, 자막 서버 로그인 세션은 로컬에 저장하며 조회 결과는 메모리에만 잠시 유지합니다. 설정의 ‘로컬 데이터 모두 삭제’로 지울 수 있습니다. 새 버전이 설치되면 아이콘에 표시하고 패널에서 변경 사항 안내를 한 번 보여줍니다.

Remote code: **No**. 실행 로직은 패키지 안에 있으며 원격 스크립트/문자열을 다운로드해 실행하지 않습니다. 자막의 MAIN 읽기 경로는 플레이어 메서드를 호출하지 않으며 재생을 시작하지 않습니다. 순차 재생은 패키지의 `player` 콘텐츠 스크립트로 영상 요소를 1x로 재생합니다. 자막 서버 응답은 닫힌 스키마로 검증한 자막 데이터로만 쓰며 코드로 실행하지 않습니다.

## 데이터 공개 — 선택적 사용 통계도 공개할 것

공식 정책은 기기 안에서만 처리하는 데이터도 공개하도록 요구합니다. 아래 사실에 맞춰 최신 대시보드 항목을 배포자가 확인합니다.

- Website content: 과목·과제·제출 상태·일정·강의명·PDF 파일명·자막을 기기에서 처리함. 선택한 PDF는 브라우저 다운로드 폴더에 저장하며 확장이 내용을 fetch·파싱·업로드하지 않음. 질문 템플릿은 명시적 클릭으로만 클립보드에 복사함. 자막 내보내기 JSON에 현재 강의 URL·제목·추출 시각을 포함함. 이 내용은 브라우저 저장소(`chrome.storage` 등)에 저장하지 않음. 예외로 순차 재생은 재생목록의 최소 과목·항목 ID와 순서만 `chrome.storage.local`에 저장함.
- 오디오/사용자 콘텐츠 전송(0.4.0): 사용자가 AI 자막 생성을 직접 시작하면 현재 강의 영상의 음성 트랙(.m4a)과 형식·크기·길이·언어를 개발자가 운영하는 자막 서버로 HTTPS 전송하고, 생성된 자막을 받아 표시함. 대시보드에서 해당 카테고리(웹사이트 콘텐츠의 오디오 등)를 ‘수집함’으로 신고함.
