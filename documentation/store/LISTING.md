# Chrome Web Store 등록 초안

상태: 배포 후보. 등록·심사 제출·게시하지 않았습니다.

## 등록 정보

- 이름: uniDock
- 기본 언어: 한국어
- 카테고리 후보: 교육(대시보드의 현재 분류 확인)
- 짧은 설명: 고려대 LMS 과제·일정·녹화·PDF 자료 조회, 자막 저장과 PDF 일괄 다운로드를 지원하는 비공식 학습 도우미.
- 0.1.1 범위: 순차 자동 재생은 검토 중이라 빌드에서 제외했습니다. 메뉴에는 비활성 항목과 “현재 검토 중인 기능입니다.” 안내만 남으므로 설명·이미지에서 기능으로 소개하지 않습니다.
- 배포자 표시명: **미정 — 사용자 입력 필요**
- 지원 이메일/지원 URL: **미정 — 공개 가능한 연락처 필요**
- 개인정보 처리방침 URL: **미정 — `npm run pages:sync` 후 GitHub Pages의 `main` → `/docs`로 게시하고, 공개 사이트의 `/privacy.html` 주소 확인 후 입력**
- 대상: 고려대학교 LMS를 이미 이용하는 사용자. 대학이 제공하거나 인증한 제품이 아님.

## 상세 설명 (복사 가능)

uniDock은 기존 고려대학교 LMS 로그인 세션으로 과목·과제·마감일·일정·녹화 강의를 확인하는 비공식 Chrome Side Panel 학습 도우미입니다.

• 과목별 과제와 제출 상태, 마감일 확인
• 할 일·일정 목록, 항목별 상세와 보기 설정
• 모듈별 녹화 강의 후보 탐색 및 사용자가 선택한 LMS/LTI 탭 열기
• 모듈 PDF 전체 또는 선택 다운로드: 다운로드/uniDock/과목/모듈/ 아래 저장
• 한국어 질문 템플릿 복사와 ChatGPT 시작 페이지 열기; PDF 첨부·제출은 사용자가 직접 수행
• 화면 자막 우선 감지, XML/VTT 한국어 우선 선택 및 시간 포함 TXT·JSON 다운로드

아이디나 비밀번호를 입력받거나 저장하지 않습니다. 개발자 서버, 외부 AI API, 분석 서비스로 LMS 정보·자막·PDF·질문을 자동 전송하지 않으며 광고·추적이 없습니다. 확장은 PDF 내용을 읽거나 업로드하지 않으며 외부 서비스 첨부·제출은 사용자가 직접 결정합니다. 과제 제출·업로드·글쓰기·수정·삭제·자동 재생·출석 위조·keepalive는 지원하지 않습니다. 메뉴의 자동 재생 항목은 현재 검토 중인 기능 안내만 표시합니다.

LMS에서 평소처럼 로그인하고 탭을 선택한 뒤 uniDock에서 조회하세요. 외부 플레이어 자막은 해당 탭에서 도구 모음 uniDock 아이콘을 눌러 임시 접근을 허용한 후 감지합니다. 화면 목록이 없으면 KU 플레이어의 XML/VTT 자막을 조회합니다. 외부 CDN의 CORS/CSP 제한 또는 플레이어 설정 구조 차이로 감지가 제한될 수 있습니다.

고려대학교와 공식 제휴 관계가 없습니다. Chrome 114 이상이 필요하며 서비스의 변경에 따라 조회가 제한될 수 있습니다. 브라우저 저장소를 사용하지 않으며 조회 결과는 패널·탭 메모리에만 잠시 유지됩니다.

## 단일 목적

사용자가 기존 고려대 LMS 세션에서 학습 자료와 일정을 확인하고, 선택한 강의·PDF·공식 한국어 자막에 접근하며, 수업 자료 PDF 일괄 다운로드를 사용할 수 있는 학습 도우미.

## 데이터 공개 — ‘서버 수집 없음’을 ‘데이터 처리 없음’으로 입력하지 말 것

공식 정책은 기기 안에서만 처리하는 데이터도 공개하도록 요구합니다. 아래 사실에 맞춰 최신 대시보드 항목을 배포자가 확인합니다.

- Website content: 과목·과제·제출 상태·일정·강의명·PDF 파일명·자막을 기기에서 처리함. 선택한 PDF는 브라우저 다운로드 폴더에 저장하며 확장이 내용을 fetch·파싱·업로드하지 않음. 질문 템플릿은 명시적 클릭으로만 클립보드에 복사함. 자막 내보내기 JSON에 현재 강의 URL·제목·추출 시각을 포함함. 브라우저 저장소(`chrome.storage` 등)에는 저장하지 않음.
- Web history/browsing activity: 전체 history API는 없지만 현재 요청한 탭 URL과 요청 대상 URL을 기능 수행에 사용함.
- Authentication information: 기존 인증 세션으로 브라우저가 쿠키를 자동 첨부함. 확장이 비밀번호·쿠키 값을 직접 읽거나 보관하지 않음을 설명함.
- Personal identifiers: API 원본에 내부 식별자가 올 수 있고 요청 중 course/item ID를 사용함. 원본 내부 ID는 출력에서 제거하며 저장하지 않음.
- 광고/판매/신용평가/기능과 무관한 목적/개발자 서버 공유/자동 외부 AI 전송: 없음. 사용자가 ChatGPT 등 외부 서비스에 직접 제출한 자료는 해당 서비스의 처리 범위임.
- Limited Use 세 가지 확인 항목은 실제 게시 방침과 일치하는 경우에만 배포자가 인증.

학습자 자막/제출 상태를 ‘아무 데이터도 처리하지 않음’으로 표시하지 않습니다. 데이터 카테고리 해석이 불명확하면 위 사실을 심사 설명에 그대로 적고 대시보드 정의에 맞춥니다.
