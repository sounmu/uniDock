- 대상: 고려대학교 LMS를 이미 이용하는 사용자. 대학이 제공하거나 인증한 제품이 아님.

## 상세 설명 (복사 가능)

uniDock은 기존 고려대학교 LMS 로그인 세션으로 과목·과제·마감일·일정·녹화 강의를 확인하는 비공식 Chrome Side Panel 학습 도우미입니다.

• 과목별 과제와 제출 상태, 마감일 확인
• 할 일·일정 목록, 항목별 상세와 보기 설정
• 모듈별 녹화 강의 후보 탐색 및 사용자가 선택한 LMS/LTI 탭 열기
• 주차학습 모듈·게시판·공지에 첨부된 강의 자료(PDF·PPTX·PPT) 조회와 전체/선택 다운로드
• 한국어 질문 템플릿 복사와 ChatGPT 시작 페이지 열기; 자료 첨부·제출은 사용자가 직접 수행
• 화면 자막 우선 감지, XML/VTT 한국어 우선 선택 및 시간 포함 TXT·JSON 다운로드

아이디나 비밀번호를 입력받거나 저장하지 않습니다. LMS 정보·자막·자료·질문을 분석 서비스나 외부 AI에 자동 전송하지 않습니다. 사용 통계는 기본 비활성이며, 정보 화면에서 동의한 경우에만 화면·버튼 사용, 기능 성공·실패, 패널 표시·활성 시간, 버전과 무작위 설치 식별자를 PostHog EU로 보냅니다. LMS 계정·내용·URL·입력값이나 화면 녹화는 수집하지 않습니다. 거절해도 모든 학습 기능을 사용할 수 있으며 언제든 철회할 수 있습니다. 광고 추적·데이터 판매는 없습니다. 확장은 파일 내용을 읽거나 업로드하지 않으며 외부 서비스 첨부·제출은 사용자가 직접 결정합니다. 자동 재생·과제 제출·업로드·글쓰기·수정·삭제·출석 위조·keepalive는 지원하지 않습니다.

LMS에서 평소처럼 로그인하고 탭을 선택한 뒤 uniDock에서 조회하세요. 외부 플레이어 자막은 해당 탭에서 도구 모음 uniDock 아이콘을 눌러 임시 접근을 허용한 후 감지합니다. 화면 목록이 없으면 KU 플레이어의 XML/VTT 자막을 조회합니다. 외부 CDN의 CORS/CSP 제한 또는 플레이어 설정 구조 차이로 감지가 제한될 수 있습니다.

고려대학교와 공식 제휴 관계가 없습니다. Chrome 114 이상이 필요하며 서비스 변경에 따라 조회가 제한될 수 있습니다. 통계 공유 설정과 동의 후 생성한 설치 식별자는 로컬에 저장하며 조회 결과는 메모리에만 잠시 유지합니다. 새 버전이 설치되면 아이콘에 표시하고 패널에서 변경 사항 안내를 한 번 보여줍니다.

사용자가 기존 고려대 LMS 세션에서 학습 자료와 일정을 확인하고, 선택한 강의·자료·공식 한국어 자막에 접근하며 자료를 다운로드할 수 있는 학습 도우미.

## 데이터 공개 — 선택적 사용 통계도 공개할 것

공식 정책은 기기 안에서만 처리하는 데이터도 공개하도록 요구합니다. 아래 사실에 맞춰 최신 대시보드 항목을 배포자가 확인합니다.

- Website content: 과목·과제·제출 상태·일정·강의명·PDF 파일명·자막을 기기에서 처리함. 선택한 PDF는 브라우저 다운로드 폴더에 저장하며 확장이 내용을 fetch·파싱·업로드하지 않음. 질문 템플릿은 명시적 클릭으로만 클립보드에 복사함. 자막 내보내기 JSON에 현재 강의 URL·제목·추출 시각을 포함함. 브라우저 저장소(`chrome.storage` 등)에는 저장하지 않음.
- Web history/browsing activity: 전체 history API는 없지만 현재 요청한 탭 URL과 요청 대상 URL을 기능 수행에 사용함.
- Authentication information: 기존 인증 세션으로 브라우저가 쿠키를 자동 첨부함. 확장이 비밀번호를 받지 않고 쿠키 값을 보관하지 않음을 설명함. 예외로 LearningX 게시판 조회 시 LMS 페이지의 게시판 토큰(`xn_api_token`)을 요청 순간에만 읽어 같은 LMS의 고정 GET 경로에만 붙이며 저장·전송하지 않음을 밝힘.
- Personal identifiers: 원본 LMS 내부 ID는 출력에서 제거하며 저장하지 않음. 별도로 사용 통계 동의 후 무작위 설치 식별자를 생성해 PostHog EU로 전송함. LMS 계정과 연결하지 않으며 재방문 연결용 가명 식별자임. 수신 서버는 통신 과정에서 IP/브라우저 헤더에 접근할 수 있고 IP 저장·위치 보강을 제한함.
- User activity: 명시적 동의 후 패널 열기·화면·버튼 종류·기능 성공/실패·표시/활성 시간·버전·이벤트 시각 및 중복 구분 ID를 PostHog EU에서 처리. 이벤트 최대 90일 보관, 요청 시 원격 삭제. DOM 자동 수집·키 입력 내용·화면 녹화·LMS 활동 내용은 미수집. 동의 전 식별자/이벤트 생성 및 전송 없음. 기본값 비활성, 거절/철회 가능.
- 제3자 제공/처리: 동의한 사용 통계를 PostHog, Inc. EU 리전으로 전송해 기능 개선·안정성 및 재방문 분석에 사용. ‘제3자 전송 없음’으로 신고하지 않음. 개발자는 이 통계를 볼 수 있으나 LMS 원문은 받지 않음.
- 광고/판매/신용평가/기능과 무관한 목적/자동 외부 AI 전송: 없음. 사용자가 ChatGPT 등 외부 서비스에 직접 제출한 자료는 해당 서비스의 처리 범위임.
- Limited Use 세 가지 확인 항목은 실제 게시 방침과 일치하는 경우에만 배포자가 인증.

학습자 자막/제출 상태를 ‘아무 데이터도 처리하지 않음’으로 표시하지 않습니다. 데이터 카테고리 해석이 불명확하면 위 사실을 심사 설명에 그대로 적고 대시보드 정의에 맞춥니다.
