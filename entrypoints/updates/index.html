간편해진 영상 선택과 재생 제어

버전

  • 검색하며 고르는 주차별 강의 목록

    강의 제목으로 검색해도 선택과 재생 순서는 유지됩니다. 선택 개수와 자동 재생 버튼은 스크롤 중에도 하단에서 바로 확인할 수 있습니다.

  • 한눈에 보는 재생목록

    현재 영상과 대기열을 하나의 작은 목록으로 모았습니다. 과목명에서 학기·괄호 표기·분반을 정리하고 현재 영상만 회색으로 구분합니다.

  • 플레이어와 함께 움직이는 재생 상태

    다른 탭으로 이동해도 확장이 재생을 멈추지 않습니다. 같은 재생 세션에서 플레이어를 직접 일시정지하거나 다시 재생하면 패널 상태도 함께 바뀌고, 영상이 끝나면 다음 항목으로 이어집니다. LMS 이수 인정은 해당 서비스에서 확인해 주세요.

  • 차분해진 패널과 명확한 삭제 확인

    좌우 여백을 늘리고 새로고침·버튼 반응을 무채색으로 통일했습니다. 로딩 문구 대신 빈 칸을 표시하며, 사용 통계 안내와 로컬 데이터 삭제 화면도 간결하게 정리했습니다.

열려 있던 LMS 탭에는 새 버전을 자동으로 다시 연결했습니다. 조회가 되지 않으면 해당 탭을 새로고침해 주세요.
