새 홈과 강의 이어보기

버전

  • 홈에서 확인하는 마감과 강의 도구

    주 메뉴를 홈·내 과목·일정·설정으로 정리했습니다. 홈에서 가까운 마감 3개를 확인하고 자동 재생과 자막 추출을 열 수 있습니다.

  • 강의 상세에서 바로 시작하는 작업

    선택한 강의에서 재생·자막 도구로 이동하고 이전 화면으로 돌아갈 수 있습니다. 메뉴를 바꿔도 재생 선택과 진행 중인 작업을 유지합니다.

  • 멈춘 강의는 기존 탭에서 재개

    LMS가 탭 전환 시 영상을 멈추면 일시정지 상태를 안내합니다. 같은 재생 세션의 플레이어에서 직접 재생하거나 ‘강의 탭에서 재개’를 누르면 현재 위치와 목록을 이어갑니다. 패널 재개가 브라우저에 차단된 뒤에도 플레이어에서 직접 재생할 수 있도록 복구 흐름을 보완했습니다.

  • 그림자를 덜어낸 진행 알림

    LMS 화면에 표시되는 진행 알약의 바깥 그림자를 없앴습니다. 진행 상태와 닫기 동작은 그대로 유지합니다.

자동 재생을 끈 뒤에는 플레이어의 재생만으로 자동 재생이 다시 켜지지 않습니다. LMS 이수 인정은 해당 서비스에서 확인해 주세요. 업데이트 뒤 조회나 재생 상태가 맞지 않으면 열려 있던 LMS·강의 탭을 새로고침해 주세요.
