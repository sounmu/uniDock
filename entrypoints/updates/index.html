패널을 닫아도 이어지는 AI 자막

버전

스토어 버전 0.6.0 이후의 변경 사항을 모았어요.

  • 진행 상태를 더 정확하게

    백그라운드가 다시 연결된 뒤에도 완료된 자막이 진행 중으로 남지 않도록 고쳤어요. 패널을 오래 열어 두어도 자막 대기열 상태가 계속 갱신돼요.

  • 여러 창의 설정 충돌 수정

    여러 창에서 팝업 자동 닫기를 바꿀 때 설정이 엇갈리던 문제를 고쳤어요.

  • 여러 강의 자막을 한 번에

    과목·주차별로 여러 강의를 골라 AI 자막을 차례로 만들 수 있어요.

  • AI 자막 하루 7회

    이용 한도가 주 7회에서 하루 7회로 늘었어요. 시작 전에 오늘 남은 횟수를 확인할 수 있어요.

  • 지금 보는 강의에서 바로

    지금 보고 있는 강의의 자막을 패널 위쪽에서 바로 만들 수 있어요.

  • 패널을 닫아도 계속

    ‘패널을 닫아도 계속 진행돼요’ 안내가 나오면 패널을 닫아도 음성 받기와 업로드, 여러 강의 자막 만들기가 이어져요. 다시 열면 진행 상태를 확인하고 취소할 수 있어요.

  • 더 빠르고 부드러운 업로드

    음성 업로드가 빨라지고, 업로드 진행률이 부드럽게 표시돼요.

  • 영어 강의는 영어 자막으로

    영어 강의는 영어로 자막을 만들어요. 같은 문장이 반복되던 문제도 고쳤어요.

  • 열린 탭 확인

    여러 강의 AI 자막을 만들 때 강의마다 열린 탭의 주소와 플레이어 수를 확인해요. 확인하지 못한 강의는 음성을 보내지 않고 다음 강의로 넘어가요.

  • 막혀도 이어서

    강의를 너무 빨리 열어 잠시 막히면 기다렸다가 같은 강의를 다시 열어요.

  • 위에 고정된 작업 줄

    진행 중인 작업과 ‘지금 보는 강의 자막 추출’, 강의 자료 선택 바가 스크롤해도 맨 위에 붙어 있어요. 진행률은 링으로 보여 줘요.

  • 한 화면에 들어오는 자막 화면

    AI 자막 카드와 여러 강의 카드가 하단 메뉴에 가리지 않고 한 화면에 들어와요.

  • 중복 안내 없이 깔끔하게

    패널을 연 창에서는 LMS 화면의 진행 알약을 숨겨요. 이미 자막을 만들고 있는 강의는 ‘지금 보는 강의 자막 추출’ 줄에 다시 나오지 않아요.

  • 자막도 uniDock 폴더에

    자막 TXT·JSON 파일을 강의 자료와 같은 uniDock 폴더에 저장해요.

  • 로딩 화면과 체크박스 개선

    로딩 중에도 실제 목록과 같은 위치에 항목을 표시해요. 체크박스를 누를 때 회색 네모가 나타나던 문제도 고쳤어요.

자동 재생을 끈 뒤에는 플레이어의 재생만으로 자동 재생이 다시 켜지지 않습니다. LMS 이수 인정은 해당 서비스에서 확인해 주세요. 업데이트 뒤 조회나 재생 상태가 맞지 않으면 열려 있던 LMS·강의 탭을 새로고침해 주세요.
