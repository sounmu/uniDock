새로워진 화면과 사용 통계·자막 개선

버전

  • 하단 탭 바

    내 과목, 할 일·일정, 자동 재생, 자막 추출, 설정을 화면 아래 탭에서 바로 오갑니다. LMS 열기는 설정 화면으로 옮겼습니다.

  • 한눈에 보이는 상태

    과제마다 제출됨, 마감 지남, 잠김 상태를 아이콘과 글자로 함께 보여줍니다.

  • 정돈된 카드

    목록과 설정을 반투명 카드로 정리하고 모서리와 여백을 하나의 기준으로 맞췄습니다.

  • 집계 방식의 사용 통계

    개인을 구분하는 ID 없이 기능 사용 횟수를 집계합니다. 설정에서 통계를 끄거나 기기에 남은 데이터를 삭제할 수 있습니다.

  • 통계 끄기·삭제 처리 개선

    아직 보내지 않은 통계를 지운 뒤 다시 사용할 때도 이용 현황이 일관되게 집계되도록 개선했습니다.

  • 자막 서버 응답 확인 강화

    지원하는 형식의 자막만 받아들이도록 서버 연결 기준을 명확히 했습니다.

열려 있던 LMS 탭에는 새 버전을 자동으로 다시 연결했습니다. 조회가 되지 않으면 해당 탭을 새로고침해 주세요.
