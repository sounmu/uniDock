uniDock 개인정보 처리방침

기준일: 2026년 9월 30일 · 적용 버전: 0.1.2

uniDock은 고려대학교와 공식 제휴 관계가 없는 비공식 학습 도우미입니다. 이 방침은 확장 프로그램의 데이터 처리에 적용됩니다.

처리하는 정보와 목적

사용자가 조회할 때 LMS의 과목명, 과제·마감·제출 상태, 일정·할 일, 녹화 강의 모듈·제목을 읽어 Side Panel에 표시합니다. 내부 과목/항목 식별자는 요청과 탭 열기 처리 중에만 사용합니다. 현재 탭의 주소는 허용 출처, 탭/문서 변경, 사용자가 선택한 강의 접근을 확인하는 데 사용합니다. 전체 방문 기록을 조회하거나 분석하지 않습니다.

자막 감지를 선택하면 현재 강의 탭 및 접근 가능한 프레임의 자막 목록을 우선 읽고, 없으면 KU 플레이어의 설정에 명시된 XML/VTT를 조회하여 한국어 자막을 우선 선택합니다. VTT가 없으면 플레이어에 이미 로드된 별도 TXT 스크립트도 읽습니다. 시간·문장·강의 URL·제목·추출 시각을 감지·표시·TXT/JSON 내보내기만을 위해 처리하며 일반 웹페이지 본문 전체를 수집하지 않습니다.

수업 자료 PDF 다운로드. 선택한 과목의 모듈에서 PDF 후보의 모듈명·파일명과 일회성 열기·다운로드 키를 처리합니다. 사용자가 다운로드를 누른 경우에만 브라우저가 기본 다운로드 폴더의 uniDock/과목/모듈/ 아래 파일을 저장합니다. 확장은 PDF 내용을 fetch·파싱·업로드하지 않습니다. 완료 상태는 확장 자신의 다운로드 이벤트와 해당 ID의 파일명·출처·상태·MIME을 메모리에서 확인하며 전체 다운로드 기록은 조회하지 않습니다. 연결이 불확실하면 요청됨, PDF가 아닌 MIME이면 확인 필요로 안내합니다. ChatGPT에서 질문하기를 선택하면 한국어 질문 템플릿을 클립보드에 복사하고 ChatGPT 시작 페이지를 엽니다. 파일 첨부·입력·제출은 사용자가 직접 수행하며 그때 해당 서비스의 방침이 적용됩니다.

강의 자동 재생은 사용자가 영상들을 직접 선택하고 시작해야 하며 기본값은 비활성입니다.

순차 자동 재생 (opt-in). 선택한 녹화 강의를 체크한 순서대로 즉시 정상(1x) 속도로 재생합니다. 최소 과목/영상 식별자, 순서와 재생 상태를 chrome.storage.local에 계정별로 저장합니다. 영상의 네이티브 종료(ended) 이벤트만 감지하며, LMS의 시청 완료/출석 인정과는 별개입니다. 출석을 위조하거나 LMS 완료/출석 API를 호출하지 않습니다. 브라우저가 실행 중이고 전용 강의 탭이 활성 상태여야 합니다. 로그인이 만료되면 재생목록을 보존한 채 중단하고 사용자가 로그인 후 명시적으로 재개해야 합니다. 강의 URL, 서명된 LTI 파라미터, 쿠키, 토큰은 저장하지 않습니다.

인증과 통신

로그인은 기존 LMS/SSO 화면에서 사용자가 직접 진행합니다. 아이디·비밀번호 입력을 받지 않고 쿠키/토큰 값을 직접 읽거나 저장하지 않습니다. 같은 출처 HTTPS 요청에는 Chrome이 기존 로그인 세션을 자동 사용합니다. LMS 조회는 필요한 GET 경로만 사용하며, 자막 파일 요청은 플레이어 설정/XML에 선언된 HTTPS XML/VTT로 제한하며 외부 출처 요청에는 인증 정보를 보내지 않습니다. API·자막 조회는 리다이렉트를 따라가지 않습니다. 사용자 요청 PDF 다운로드는 Chrome이 LMS의 파일 리다이렉트를 처리할 수 있습니다.

개발자 서버, 외부 AI API, 광고 서버, 분석 서비스로 LMS 정보·자막·PDF·질문을 자동 전송하지 않습니다. 데이터를 판매하거나 광고·프로파일링·모델 학습에 사용하지 않습니다. 조회 요청은 해당 LMS/자막 제공 서버로만 전송됩니다. 별도로 동의한 경우 아래의 최소 사용 통계를 PostHog에 전송합니다. 사용자가 LTI 탭 또는 외부 LLM 사이트를 열고 직접 자료를 제출하면 해당 서비스의 인증·방문·콘텐츠 처리와 방침이 적용됩니다.

선택적 사용 통계 (PostHog)

기본값은 수집 안 함입니다. 정보 화면에서 수집 항목과 목적을 확인하고 ‘동의하고 통계 공유’를 누른 경우에만 무작위 설치 식별자를 생성·저장하고 전송을 시작합니다. 거절하거나 철회해도 모든 학습 기능을 사용할 수 있습니다. 동의 이전 활동을 보관하거나 나중에 소급 전송하지 않습니다.

기능 개선과 안정성 확인을 위해 패널 열기, 정해진 화면 이름, 버튼 동작 종류, 기능 성공·실패, 패널 표시 시간·활성 시간(초), 확장 버전, 이벤트 시각과 중복 구분용 이벤트 식별자를 수집합니다. 무작위 설치 식별자는 LMS 계정과 연결하지 않지만 같은 설치의 활동을 연결할 수 있는 가명 식별자입니다. 이를 통해 동의한 설치의 일간·주간·월간 이용 및 재방문을 집계합니다. 정확한 사람 수나 영상 시청 시간·출석을 측정하는 기능이 아닙니다.

수신 서비스는 PostHog(제공자: PostHog, Inc., EU 리전, https://eu.i.posthog.com)이며 HTTPS로 전송합니다. 서비스 제공 과정에서 IP 주소와 브라우저의 통신 헤더가 수신 서버에 전달될 수 있습니다. IP 저장 및 위치 보강을 제한하며 쿠키·LMS 인증 정보를 첨부하지 않습니다. LMS 내용, 과목·과제·영상·파일 이름과 식별자, 이름·이메일·학번·계정 식별자, URL·페이지 제목, 자막·파일 내용, 입력값, 원본 오류는 분석 데이터에 넣지 않습니다. 화면 녹화, 자동 DOM 수집, 히트맵, 광고 추적 및 원격 기능 설정을 사용하지 않습니다.

정보 화면의 ‘통계 공유 철회’는 이후 수집을 중단하고 로컬 설치 식별자를 삭제합니다. ‘로컬 데이터 모두 삭제’는 통계 동의와 식별자도 지우고 수집을 기본 비활성 상태로 되돌립니다. 확장 제거도 로컬 데이터를 삭제합니다. 네트워크 장애나 종료 때 전송되지 않은 이벤트는 재전송용으로 디스크에 저장하지 않습니다.

이미 수신된 사용 이벤트는 최대 90일 보관 후 삭제합니다. 동의 철회·로컬 데이터 삭제·확장 제거는 이미 전송된 이벤트를 소급 삭제하지 않습니다. 원격 통계 삭제를 요청하려면 철회 또는 로컬 삭제 전에 정보 화면의 ‘통계 삭제 요청용 식별자’를 복사하여 스토어 지원 연락처로 보내주세요. 이 식별자 외에 학번·LMS 계정 정보는 보내지 마세요. 운영자는 해당 설치의 원격 이벤트를 삭제합니다.

보관과 삭제

검증·투영된 과목 목록의 캐시 재사용 기한은 2분, 과제·마감·할 일·일정 목록은 30초입니다. 만료된 항목은 다시 표시하지 않고 다음 캐시 접근 또는 LMS 탭 이동·종료 때 content script 메모리에서 제거합니다. 캐시를 읽기 전 현재 LMS 계정을 다시 확인하고 계정 변경·로그인 만료 시 전체를 폐기하며, 사용자가 누른 새로고침은 캐시를 우회합니다. 원본 API 응답과 일회용 키가 포함된 녹화·PDF 목록은 캐시하지 않습니다. 일회성 강의·PDF 열기·다운로드 키는 content script 메모리에서 최대 5분 유지합니다. 다운로드 진행 상태는 패널 메모리에만 두며 패널 종료 시 사라집니다. 자막도 패널 메모리에 최대 5분 유지합니다. 자동 재생 시작 시 최소 과목/영상 식별자, 순서와 상태를 계정별 chrome.storage.local에 보관합니다. 계정 구분용 기기별 무작위 salt와 진행 중인 전용 탭의 번호·항목 식별자도 재시작 검증용으로 로컬에 보관합니다. 일시적인 탭 소유권 확인 정보는 chrome.storage.session에 보관합니다. 쿠키, 토큰, 원본 API 응답 전체, 일회성 선택 키, 영상 라벨, 서명된 LTI URL, LTI 플레이어 원본 설정은 저장하지 않습니다. 재생목록은 완료·중지·사용자 삭제 전까지 유지될 수 있으며, 사용자는 패널에서 저장된 데이터를 즉시 삭제할 수 있습니다. 별도로 통계 공유 선택과 동의한 설치의 무작위 식별자를 chrome.storage.local에 보관합니다. IndexedDB 및 LMS 데이터 로그는 사용하지 않습니다. 사용자가 자막을 내보내면 현재 강의 URL(쿼리 포함)이 JSON에 저장됩니다. PDF는 다운로드를 누른 경우에만 브라우저가 파일로 저장합니다.

사용자가 TXT·JSON 다운로드를 누르면 시간과 문장을 TXT로, 강의 URL·제목·추출 시각·항목 수·시간·문장을 JSON으로 브라우저 다운로드 폴더의 output/ 아래 저장 요청합니다. 이 파일과 다운로드한 PDF는 암호화되지 않으며 사용자가 직접 관리·삭제합니다. 확장을 제거해도 이미 다운로드한 파일 및 Chrome/LMS 자체 기록은 삭제되지 않습니다.

권한

sidePanel은 화면 제공, 두 LMS 호스트 권한은 로그인된 LMS 조회, activeTab과 scripting은 사용자가 확장 아이콘을 누른 강의 탭의 자막 읽기와 허용된 플레이어 제어에 필요합니다. KU 플레이어 호스트 권한은 해당 iframe의 자막 읽기와 사용자가 시작한 순차 자동 재생에 사용합니다. downloads 권한은 output/ 하위 자막과 uniDock/ 하위 PDF 저장 요청, 다운로드 폴더 열기 및 확장 자신의 PDF 다운로드 상태 확인에 사용합니다. storage 권한은 계정별 최소 재생목록 상태와 통계 공유 선택·설치 식별자에, alarms 권한은 진행 중인 재생의 제한된 lease/watchdog 확인에 사용합니다. cookies, history, tabs(광범위), debugger 권한이나 모든 사이트 상시 접근 권한은 요청하지 않습니다.

Limited Use

uniDock의 사용자 데이터 사용은 Chrome Web Store 사용자 데이터 정책 및 Limited Use 요구사항을 준수하도록 설계되었습니다. 데이터는 위에 명시한 사용자 요청 기능과 동의한 사용 통계를 통한 기능 개선·안정성 확인에만 사용합니다. 개발자는 LMS 정보와 자막을 서버에서 수집하거나 열람하지 않으며 제3자에게 판매·공유하지 않습니다.

문의와 변경

개인정보 문의는 Chrome Web Store uniDock 등록 페이지에 표시된 배포자의 지원 연락처로 보내주세요. 문의에 비밀번호, 쿠키, 토큰, 실제 LMS 응답 또는 개인 자막을 첨부하지 마세요. 데이터 처리 방식이 바뀌면 이 방침과 스토어 고지를 함께 갱신합니다.
