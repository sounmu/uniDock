uniDock 개인정보 처리방침

기준일: 2026년 9월 25일 · 적용 버전: 0.1.0

uniDock은 고려대학교와 공식 제휴 관계가 없는 비공식 학습 도우미입니다. 이 방침은 확장 프로그램의 데이터 처리에 적용됩니다.

처리하는 정보와 목적

사용자가 조회할 때 LMS의 과목명, 과제·마감·제출 상태, 일정·할 일, 녹화 강의 모듈·제목을 읽어 Side Panel에 표시합니다. 내부 과목/항목 식별자는 요청과 탭 열기 처리 중에만 사용합니다. 현재 탭의 주소는 허용 출처, 탭/문서 변경, 사용자가 선택한 강의 접근을 확인하는 데 사용합니다. 전체 방문 기록을 조회하거나 분석하지 않습니다.

자막 감지를 선택하면 현재 강의 탭 및 접근 가능한 프레임의 자막 목록을 우선 읽고, 없으면 KU 플레이어의 설정에 명시된 XML/VTT를 조회하여 한국어 자막을 우선 선택합니다. VTT가 없으면 플레이어에 이미 로드된 별도 TXT 스크립트도 읽습니다. 시간·문장·강의 URL·제목·추출 시각을 감지·표시·TXT/JSON 내보내기만을 위해 처리하며 일반 웹페이지 본문 전체를 수집하지 않습니다.

공지 캘린더는 사용자가 조회할 때 작동합니다. 강의 예약 재생은 과목별로 명시적으로 켜야 하며 기본값은 비활성입니다.

공지 캘린더. 공지 본문에서 날짜·시각·행위의 후보를 기기 안에서 추출하여 과제·공식 일정과 함께 표시합니다. 공지 게시일을 행사일로 간주하지 않고 모호한 후보와 마감 충돌은 확인 필요로 표시합니다. 조회 결과와 원문은 기본적으로 패널 메모리에만 두며, 사용자가 일정을 수정·제외할 때 이벤트 식별자·원문 개정 시각·수정값만 계정별 chrome.storage.local에 보관합니다. 공지 알림을 예약하지 않으며 원본 공지 HTML 전체를 저장하지 않습니다.

예약 재생 (opt-in). 과목별로 선택한 녹화 강의를 마감 전 지정 시간대에 정상(1x) 속도로 재생합니다. 재생 설정(활성 여부, 선택 과목, 시간대)과 최소 예약 상태를 chrome.storage.local에 계정별로 저장합니다. 영상의 네이티브 종료(ended) 이벤트만 감지하며, LMS의 시청 완료/출석 인정과는 별개입니다. 출석을 위조하거나 LMS 완료/출석 API를 호출하지 않습니다. 브라우저가 실행 중이고 전용 강의 탭이 활성 상태여야 하며, PC가 꺼져 있거나 브라우저가 닫혀 있으면 예약 재생은 실행되지 않습니다. 강의 URL, 서명된 LTI 파라미터, 쿠키, 토큰은 저장하지 않습니다.

인증과 통신

로그인은 기존 LMS/SSO 화면에서 사용자가 직접 진행합니다. 아이디·비밀번호 입력을 받지 않고 쿠키/토큰 값을 직접 읽거나 저장하지 않습니다. 같은 출처 HTTPS 요청에는 Chrome이 기존 로그인 세션을 자동 사용합니다. LMS 조회는 필요한 GET 경로만 사용하며, 자막 파일 요청은 플레이어 설정/XML에 선언된 HTTPS XML/VTT로 제한하며 외부 출처 요청에는 인증 정보를 보내지 않습니다. 리다이렉트는 따라가지 않습니다.

개발자 서버, 외부 AI, 광고 서버, 분석 서비스로 LMS 정보나 자막을 전송하지 않습니다. 데이터를 판매하거나 광고·프로파일링·모델 학습에 사용하지 않습니다. 조회 요청은 해당 LMS/자막 제공 서버로만 전송됩니다. 사용자가 LTI 탭을 열면 LMS와 해당 제공자의 인증·방문·시청 기록 처리가 발생할 수 있으며 그 서비스의 방침이 적용됩니다.

보관과 삭제

조회 결과와 선택한 과목은 패널 메모리에만 두며 기능/필터 변경 또는 재조회 시 교체됩니다. 패널 종료 시 목록은 사라집니다. 일회성 강의 선택 키는 content script 메모리에서 최대 5분, 자막은 패널 메모리에서 최대 5분 유지합니다. 일정 수정·제외 또는 예약 재생 설정 시 변경 내역, 최소 과목/영상 식별자, 설정과 예약 상태를 계정별 chrome.storage.local에 보관합니다. 계정 구분용 기기별 무작위 salt와 진행 중인 전용 탭의 번호·항목 식별자도 재시작 검증용으로 로컬에 보관합니다. 일시적인 탭 소유권 확인 정보는 chrome.storage.session에 보관합니다. 쿠키, 토큰, 원본 API 응답 전체, 서명된 LTI URL, LTI 플레이어 원본 설정은 저장하지 않습니다. 종료된 재생 기록은 30일 후 정리하고, 사용자는 설정 화면에서 저장된 데이터를 즉시 삭제할 수 있습니다. IndexedDB, telemetry 및 LMS 데이터 로그는 사용하지 않습니다. 사용자가 자막을 내보내면 현재 강의 URL(쿼리 포함)이 JSON에 저장됩니다.

사용자가 TXT·JSON 다운로드를 누르면 시간과 문장을 TXT로, 강의 URL·제목·추출 시각·항목 수·시간·문장을 JSON으로 브라우저 다운로드 폴더의 output/ 아래 저장 요청합니다. 이 파일은 암호화되지 않으며 사용자가 직접 관리·삭제합니다. 확장을 제거해도 이미 다운로드한 파일 및 Chrome/LMS 자체 기록은 삭제되지 않습니다.

권한

sidePanel은 화면 제공, 두 LMS 호스트 권한은 로그인된 LMS 조회, activeTab과 scripting은 사용자가 확장 아이콘을 누른 강의 탭의 자막 읽기와 허용된 플레이어 제어에 필요합니다. KU 플레이어 호스트 권한은 해당 iframe의 자막 읽기와 사용자가 활성화한 예약 재생에 사용합니다. downloads 권한은 output/ 하위에 자막 파일을 저장 요청하는 데 사용합니다. storage 권한은 계정별 일정 수정·제외와 예약 설정·상태에, alarms 권한은 사용자가 켠 강의 예약 시작에 사용합니다. 캘린더 알림은 제공하지 않습니다. cookies, history, tabs(광범위), debugger 권한이나 모든 사이트 상시 접근 권한은 요청하지 않습니다.

Limited Use

uniDock의 사용자 데이터 사용은 Chrome Web Store 사용자 데이터 정책 및 Limited Use 요구사항을 준수하도록 설계되었습니다. 데이터는 위에 명시한 사용자 요청 기능에만 사용합니다. 개발자는 LMS 정보와 자막을 서버에서 수집하거나 열람하지 않으며 제3자에게 판매·공유하지 않습니다.

문의와 변경

개인정보 문의는 Chrome Web Store uniDock 등록 페이지에 표시된 배포자의 지원 연락처로 보내주세요. 문의에 비밀번호, 쿠키, 토큰, 실제 LMS 응답 또는 개인 자막을 첨부하지 마세요. 데이터 처리 방식이 바뀌면 이 방침과 스토어 고지를 함께 갱신합니다.
