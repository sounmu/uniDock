uniDock 개인정보 처리방침

기준일: 2026년 9월 11일 · 적용 버전: 0.1.0

uniDock은 고려대학교와 공식 제휴 관계가 없는 비공식 학습 도우미입니다. 이 방침은 확장 프로그램의 데이터 처리에 적용됩니다.

처리하는 정보와 목적

사용자가 조회할 때 LMS의 과목명, 과제·마감·제출 상태, 일정·할 일, 녹화 강의 모듈·제목을 읽어 Side Panel에 표시합니다. 내부 과목/항목 식별자는 요청과 탭 열기 처리 중에만 사용합니다. 현재 탭의 주소는 허용 출처, 탭/문서 변경, 사용자가 선택한 강의 접근을 확인하는 데 사용합니다. 전체 방문 기록을 조회하거나 분석하지 않습니다.

자막 감지를 선택하면 현재 강의 탭 및 접근 가능한 같은 출처 프레임의 한국어 자막 트랙과 이미 로드된 플레이어 자막을 읽습니다. 감지·표시·TXT 내보내기만을 위해 처리하며 일반 웹페이지 본문 전체를 수집하지 않습니다.

인증과 통신

로그인은 기존 LMS/SSO 화면에서 사용자가 직접 진행합니다. 아이디·비밀번호 입력을 받지 않고 쿠키/토큰 값을 직접 읽거나 저장하지 않습니다. 같은 출처 HTTPS 요청에는 Chrome이 기존 로그인 세션을 자동 사용합니다. LMS 조회는 필요한 GET 경로만 사용하며, 자막 파일 요청은 선언된 같은 출처 HTTPS 자막 경로로 제한합니다.

개발자 서버, 광고 서버, 분석 서비스로 LMS 정보나 자막을 전송하지 않습니다. 데이터를 판매하거나 광고·프로파일링·모델 학습에 사용하지 않습니다. 조회 요청은 해당 LMS/자막 제공 서버로만 전송됩니다. 사용자가 LTI 탭을 열면 LMS와 해당 제공자의 인증·방문·시청 기록 처리가 발생할 수 있으며 그 서비스의 방침이 적용됩니다.

보관과 삭제

조회 결과와 선택한 과목은 패널 메모리에만 두며 탭 전환과 탐색에도 유지합니다. 과목 목록은 메뉴로 돌아올 때 재사용하며 새로고침으로 갱신합니다. 다른 결과는 기능/필터 변경 또는 재조회 시 교체하고, 로그인/권한 오류가 확인되면 보관한 과목 목록도 지웁니다. 패널 종료 시 목록은 사라집니다. 일회성 강의 선택 키는 content script 메모리에서 최대 5분, 자막은 패널 메모리에서 최대 5분 유지합니다. 확장 storage, local/session storage, IndexedDB, telemetry 및 LMS 데이터 로그를 사용하지 않습니다. 원본 응답과 원본 LTI URL을 파일로 저장하지 않습니다.

사용자가 TXT 다운로드를 누르면 검증된 자막만 일반 UTF-8 텍스트 파일로 저장 요청합니다. 이 파일은 암호화되지 않으며 사용자가 직접 관리·삭제합니다. 확장을 제거해도 이미 다운로드한 파일 및 Chrome/LMS 자체 기록은 삭제되지 않습니다.

권한

sidePanel은 화면 제공, 두 LMS 호스트 권한은 로그인된 LMS 조회, activeTab과 scripting은 사용자가 확장 아이콘을 누른 강의 탭에서 제한된 자막 읽기를 수행하는 데 필요합니다. cookies, downloads, history, storage 권한이나 모든 사이트 상시 접근 권한을 요청하지 않습니다.

Limited Use

uniDock의 사용자 데이터 사용은 Chrome Web Store 사용자 데이터 정책 및 Limited Use 요구사항을 준수하도록 설계되었습니다. 데이터는 위에 명시한 사용자 요청 기능에만 사용합니다. 개발자는 LMS 정보와 자막을 서버에서 수집하거나 열람하지 않으며 제3자에게 판매·공유하지 않습니다.

문의와 변경

개인정보 문의는 Chrome Web Store uniDock 등록 페이지에 표시된 배포자의 지원 연락처로 보내주세요. 문의에 비밀번호, 쿠키, 토큰, 실제 LMS 응답 또는 개인 자막을 첨부하지 마세요. 데이터 처리 방식이 바뀌면 이 방침과 스토어 고지를 함께 갱신합니다.
